RielVest API

Cambodian (CSX) market data and a transparent analysis engine. This host serves JSON only — the interface lives elsewhere.

  • /api/health — status and data sources
  • /api/market/digest — the daily briefing
  • /api/market/levels — price levels across the board
  • /api/companies — listed companies and analysis

Figures come from Cambodia's public financial datasets and the exchange's own feeds. Values that cannot be sourced are reported as unavailable rather than estimated. Source.
